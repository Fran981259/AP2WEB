## 2. PADRÕES IDENTIFICADOS (Nível 2 — recorrência + causa raiz)

### P1 — Mudanças cross-cutting incompletas (3 ocorrências)
- FASE 4 aplicada a 7 funções mas esqueceu `_avg_stats_detail` (EVT-006)
- Filtro as-of mal aplicado no `predict_match` (EVT-012)
- Espaços faltantes em queries concatenadas (3 ocorrências)
- **Causa raiz:** inexistência de suíte de regressão automatizada + ausência de checklist "grep todos os call sites" na Backend Skill.

### P2 — Correção que gera nova regressão (3 ocorrências)
- Dedup com Map spread → bug de transpilação (EVT-09)
- `.app` flex → layout encolhido (EVT-10)
- Font declarada sem load (EVT-04)
- **Causa raiz:** teste proporcional demais ao risco real. Mudanças classificadas como "baixo risco/CSS" tinham efeito comportamental. E2E em browser só foi adotado tardiamente — e quando adotado, encontrou todas as causas raiz rapidamente.

### P3 — Diagnóstico tardio por tentativa e erro
- Vários ciclos "usuário reporta → tentativa → usuário reporta de novo" antes da adoção de medição sistemática (selenium/DOM/screenshots).
- **Causa raiz:** QA Skill não exige evidência de browser real para mudanças visuais/comportamentais.

### P4 — Drift de ambiente sem detecção proativa
- Usuários desaparecidos, temporadas vazias, ligas órfãs: tudo descoberto pelo USUÁRIO, não por health checks.
- **Causa raiz:** `/api/health` só verifica app+db; não valida usuários, cobertura de dados, integridade de temporada.

### P5 — Ponto forte confirmado
- Quando medição sistemática foi usada, TODAS as causas raiz foram encontradas e corrigidas com evidência. Zero chutes finais.
