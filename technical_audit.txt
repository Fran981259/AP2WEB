### 1.5 Motor de Aprendizado (Learning Engine)
Arquivo: `learning.py:334 linhas`

**Parâmetros otimizados por liga** (armazenados em `league_models`):
- `home_advantage`: float em grade `[1.0, 1.05, ..., 1.30]` (7 valores)
- `window`: int em grade `[5, 8, 10, 12, 15]` (5 valores) — jogos recentes para média
- `feature`: `"xg"` | `"goals"` | `"blend"` (média simples xG + gols)

**Metodologia**:
1. **Backtest honesto**: para cada jogo N, usa apenas jogos 1..N-1 (sem vazamento)
2. **Grid search**: testa todas as combinações (7×5×3 = 105 por liga)
3. **Métricas**:
   - **Acurácia 1X2**: % onde o favorito (maior prob.) acertou resultado
   - **Brier score**: erro quadrático médio das probs 1X2 vs resultado real (penaliza confiança excessiva)
4. **MIN_SAMPLES=30**: ligas com < 30 jogos jogados são puladas
5. **Storage**: melhor combinação salva em `league_models` por `league_id`

**Funções chave**:
- `backtest_league(league_id, ha, window, feature)` — retorna acurácia, Brier, series de curva
- `calibrate_league(league_id)` — grid search + persiste modelo
- `calibrate_all()` — iterar todas as ligas, pula as que têm < 30 jogos
- `model_status()` — retorna status de todas as ligas
- `motor_curve(buckets=20)` — curva de aprendizado acumulada média por % temporada, ponderada por amostras

### 1.6 Serviço de Previsão
Arquivo: `prediction.py:244 linhas`

**Fluimento**:
1. `_model_for(league_id)` → chama `get_model()` → busca `league_models` ou usa fallback `xg/1.15/10`
2. `_avg_stats(league_id, team_id, window, feature)` → média de gf/ga dos últimos N jogos
3. `_window_values()` → extrai xG ou gols dependendo da feature
4. `_build()` → monta `MatchInput` → chama `model.py:run_predict()` com `home_advantage`
5. Retorna: lambdas, probs 1X2, top_scores, proposals (1X2, Over/Under, BTTS, placar), compare H2H, form, recent games

**Endpoints**:
- `predict_match(match_id)` — previsão para partida existente
- `predict_league_upcoming(league_id, limit=10)` — próximas partidas da liga
- `predict_fixture(league_id, home_id, away_id)` — previsão de confronto arbitrário (usado pelo frontend)

### 1.7 Histórico de Previsões
Arquivo: `history.py:141 linhas`

## 3. MOTOR DE PREVISÃO DETALHADO (Poisson)

### 3.1 Modelo Matemático
- **Distribuição de Poisson**: para modelar contagem de gols
- **Lambdas (λ)**: médias de gols esperados
  - `λ_home` = média gols casa × home_advantage
  - `λ_away` = média gols visitante
- **Probabilidades 1X2**: calculadas a partir da distribuição bivariada de Poisson

### 3.2 Input (`model.py` - não lido integralmente, mas inferido)
```python
MatchInput(home=TeamInput(λ, ...), away=TeamInput(λ, ...))
run_predict(mi, home_advantage=ha) → retorna probs["1x2"] + top_scores + proposals
```

### 3.3 Grade de Otimização (learning.py:21-23)
```
HOME_ADVANTAGE_GRID = [1.0, 1.05, 1.10, 1.15, 1.20, 1.25, 1.30]  # 7 valores
WINDOW_GRID = [5, 8, 10, 12, 15]                                    # 5 valores
FEATURE_GRID = ["xg", "goals", "blend"]                              # 3 valores
```
Combinações totais por liga: 7 × 5 × 3 = 105

### 3.4 Curva de Aprendizado (motor_curve)
- Agrupa ligas calibradas
- Para cada liga, reamostra sua series de backtest para `buckets` pontos (padrão 20)
- Pondera por `sample_count` (número de jogos)
- Retorna acurácia média acumulada por % de temporada (0% → 100%)
